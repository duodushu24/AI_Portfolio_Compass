# C-026：收益曲线缩放与缺失区间说明

## 原因与实际修改

用户反馈 C-025 的点线断开、横轴只能看到约一个月。当前绘图在收益字段为空时中断线段；此前为最密日期间隔预留固定宽度，将整段时间轴放大，导致长画布。仅凭截图不能确认具体账户缺失的金融资料，本批不读取或修改真实账目来补值。

- 改为窗口内默认全区间展示，保持实际日期位置，不再为标签扩展横向画布；横轴标签按可用空间分两行自动疏密，所有观察点保留，悬停/聚焦提供完整日期和数值。
- 支持鼠标滚轮以光标位置缩放、放大/缩小/全部按钮、放大后的拖动平移、底部全区间概览及双端范围手柄。范围保持在合法边界，最小一天；切换收益指标保留范围，缩放只改变查看区间，不重算摘要。
- 灰点继续保持指标空值，显示缺失说明，不视为零。相邻已知值之间有缺失记录时绘制独立虚线，并注明中间没有收益数值；不填补任何缺失点。统计期遇连续区间编号变化仍不连接，累计口径不因净值区间编号变化清零。
- 纵轴继续明确包含零线，缩放后按可见记录及边界已知观察调整范围；既有金额遮罩、交易分组及同日记录展开保留。不新增图表库、后端字段或存储变更。

## 验证与限制

- `npm run test:portfolio-chart` 7 项通过：既有指标/日期/日记录/零刻度，以及新增全区间适配、窗口锚点/边界/手柄约束、缺失虚线和统计期跨区间断开。
- TypeScript/Vite 构建通过，保留既有大包提示。后端金融计算未修改，本轮未重跑账本测试或全量测试。
- 虚构历史样本直接挂载实际图表组件，无应用服务；离线浏览器通过真实鼠标和滚轮完成 19 项检查：全区间及窄屏适配、缺失虚线/灰点说明、放大缩小、拖动平移、底部手柄、指标切换保留范围、全部恢复、日期不重叠、跨统计区间不连线、累计口径、单点边界及无脚本错误。截图已目视核对。
- 范围手柄检查首次失败的原因是隔离页仅导入图表组件、漏加载其宿主页面的图表样式；补齐隔离页样式后真实鼠标检查通过，未因此改写业务代码。临时脚本、样本及截图在忽略的 `.runtime/c026/`，未提交。
- 未启动/重启前后端，未访问真实账户数据库或外部行情/模型。虚线只提供缺失区间的视觉衔接，不表示具备中间日收益或真实连续行情。实际账户缺失原因及用户页面体验仍待验收。
