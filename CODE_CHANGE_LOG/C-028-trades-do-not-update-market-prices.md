# C-028：买卖不再更新市值价及报价日期

## 原因与实际修改

用户指出录入买入记录会让市值更新日期变化，随后明确成交价未必是收盘价，所有买卖不应更新市值价。旧实现对普通账户将每笔成交派生为报价；C-027 的日期列直接显示采用报价的实际时间，因此也显示了成交日期。

- 重放不再从成交生成报价，仅期初确认和独立估值可写入价格缓存；已标记为成交来源的报价也不作市场估值使用。取消按导入/普通账户分叉的两套价格缓存，所有账户遵循同一规则，旧来源字段保留而不迁移数据库。
- 已有报价按交易后的数量计算市值，保留原价格和日期。首次买入若无可用报价则价格/日期未知，沿用现有具体补录提示；不增加成交参考价或新的前端展示分支。交易、更正和作废仍维护数量、成本、现金及清仓收益，跨账户成交不覆盖同标的报价。
- 定向验证发现：缺价持仓全部卖出后，当前资产可算但卖出前资产不可算，原净值更新分支跳过了该点，使收益率等到下一事件才恢复。现对无外部资金的已知当前资产立即重算净值；真正缺资金边界的收益率仍不恢复。
- 同步账户起点、普通买卖和银行黄金录入提示，删除“首次成交价自动作为报价”的旧说明。历史成交不需要删除或重录，后续读取按新规则派生；独立报价、原账目和真实运行数据不改写。

## 验证与限制

- 41 项定向服务检查通过（隔离 SQLite，`DATABASE_URL=sqlite://`）：报价/缺失契约、基准、历史汇率、只读重放，以及选定累计结转、成本、资金、份额、申购/赎回、转托管、历史纠错和零起点场景。
- 其中新增 8 项结果覆盖无旧策略/旧手工策略/旧导入策略下买卖、纠错和作废保留报价及原日期；股票、基金和银行黄金首次买入不生成报价，独立补录后恢复且不倒填未来价格；跨账户成交不更新报价或制造报价观察点；无报价全部卖出后立即恢复金额及收益率。
- 首次 32 项选测中，31 项通过，分红及资金流场景暴露了上述清仓后净值延迟；修复计算分支并新增直接回归后，41 项通过。旧零起点与申购测试改为显式补录估值；少量既有接口测试中依赖自动报价的预期同步调整，但本轮未运行这些接口用例，未重试 C-027 已记录的 TestClient 阻塞。
- TypeScript/Vite 构建通过，保留既有大包提示。前端只改录入文案，日期列与图表结构未改；按风险未重跑既有离线浏览器或全套测试。
- 本轮不启动/重启前后端，不读取或修改真实账目，不接外部行情或模型。市值及派生收益会按独立报价重算，事实记录不变；仅原先由成交价支撑、没有独立报价的持仓会改为缺价。实际账户页面体验仍待用户验收。
