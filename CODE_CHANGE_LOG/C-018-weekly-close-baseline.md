# C-018：收盘收益基准、周度估值补录与估算汇率标记

关联 [P-005](../issues/P-005-portfolio-return-history.md) 与 [S-002](../issues/solutions/P-005/S-002-account-ledger-performance.md)。按用户已确认的估值日期、收盘价格、汇率端点及线性插值授权实施；本轮不增加行情连接、每日补价或重建原交易。

## 实际变更

- 复用估值事件保存整体组合基准。原账本完整重放，基准覆盖全部纳入账户并有正净资产时，单独重置收益份额、净值和区间；不改期初成本、资金、分红或清仓阶段。基准后的真实资金流继续调整份额，边界缺价仍禁止虚假收益率。
- 支持同一交易日不同市场实际收盘时点组成完整观察；严格报价模式只在声明的同日观察使用该批真实报价。原有旧价限制和当前参考估值保持，当前参考收益由最新已知资产、实际现金及该基准计算，不回写历史。
- 汇率保留显式估算标记和用户确认来源，估算历史点及区间说明可查。前端按收盘交易日标注起点和详情，观察模式连接已保存估值，期间买卖等记录继续进入账本，不制造每日价格。
- 先在正式恢复副本的隔离副本试录，再在事务中校验并写入正式系统，仅新增估值事件；原表和原事件内容逐项核对未变。既有最新报价不改日期，不把缺失的最近美股收盘价冒充为已补齐。私有清单、来源链接、恢复副本及结果仅在已忽略运行目录。

## 验证与限制

- 最终 16 项相关后端用例通过，包括新基准、同日跨市场收盘、估算汇率、历史点详情一致、当前现金变化、基准作废、缺失资金边界、补齐边界及原转账/清空再入金行为；未跑完整测试集。
- 另发现既有联合导入测试仍断言分红不抵扣成本；用 HEAD 原始服务和业绩代码复现同样失败，属于 C-017 口径变更后尚未更新的旧预期。本轮未修改该既有测试，最终直接相关回归中明确排除这一项，不声明全部测试通过。
- 前端 TypeScript/Vite 构建通过。正式隔离试录与实际写入的全部选定收盘点、当前资产及收益结果一致；原始账本数量、成本、现金、分红和清仓状态逐项一致。
- 正式后端重载后，HTTP 与独立无界面浏览器验证曲线连续、基准交易日显示、历史点抽屉和估算提示，无 JS 异常；最初浏览器检查未展开提示详情，修正检查步骤后通过。浏览器检查后再次核对原数据未改，仅本轮估值新增。
- 周度历史包含授权估算汇率；当前末端仍可能使用保留原日期的旧行情，不能称为每日或实时精确收益。用户实际使用验收仍由 P-005 跟踪。
