# C-009：账户名称显示与收益口径说明

关联 [P-005](../issues/P-005-portfolio-return-history.md)，在 C-008 的实际使用反馈上修正显示。用户要求账户名称替代内部 ID，并质疑清仓已实现利润与账户自建档盈亏为何不同。

## 核对结论与实际修改

只读核对指定账户的期初、成交和汇率事实后，成本利润与自建档业绩能够勾稽：卖出利润按历史平均成本结转，包含建档时已有浮盈；账户业绩从期初市值和现金开始，随后买入费用也减少账户资产。此处差异来自计算起点与币种，不是少计卖出现金。金融公式和真实账目未更改。私有账户明细及核对材料仅留在忽略的本地运行目录，正文与测试只写通用结论和虚构资料。

`/api/portfolio/overview` 增加普通账户 ID 到展示名称的元信息，包含所选范围的转账对方，查询时读取最新名称；内部关联继续使用 ID。持仓/已清仓表、标的成交记录、观察点现金与待到账明细、转账内容及旧来源查询统一展示名称。缺少名称时展示“未命名账户”，不拿 ID 当可读名称。

持仓表设置明确列宽与横向滚动，账户、名称/代码和持有状态分行；长名称允许换行，避免账户内容挤入数量列。数据页的不可跳转标的使用文字展示，详情入口仍保留可点击标的。

账户指标下新增收益口径说明和可展开的计算依据，展示收益起点、期初总资产、当前总资产、净外部入金及金额公式。解释为何已实现盈亏可能包含期初浮盈/浮亏，避免把卖出利润额外加到账户总资产中。不增加第二套财务计算或重新录入要求。

## 验证与限制

- 新增 2 个隔离后端测试通过：虚构外币持仓期初浮盈、清仓及后续买入费用与账户业绩的勾稽；转账对方名称与账户改名后的映射刷新。未运行无关全套测试。
- `npm run build` 通过；收尾账户选择器缺名显示只做直接 TypeScript 检查。既有大包提示保留。
- 隔离 Edge/FastAPI/Vite 使用虚构账户验证名称不显示为 ID、长名称与数量列不重叠、账户盈亏计算依据、清仓详情与成交名称；无 JS 异常，合成截图另作视觉核对。实际 OpenD、行情与外部模型不调用。
- 真实账户只读核对，不代表对原始价格、平均成本来源或市场数据真实性作外部审计。真实金额未写入公开记录或测试，用户已有无关改动保留。

本地实施提交已回填，未推送。项目记忆检查通过（14 条记录、2 条当前方案、0 个错误）；隔离验证服务已停止。P-005 继续等待用户整体使用验收，不因一次显示修正自动关闭。
