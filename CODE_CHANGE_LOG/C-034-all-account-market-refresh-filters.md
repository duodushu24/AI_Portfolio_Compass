# C-034：统一更新市值与事项筛选

## 实际修改

用户要求资产组合提供统一市值更新按钮，账户记账增加事项筛选；结合截图，将“给事项价格筛选功能”理解为给事项加筛选，无数值价格区间要求。

- 在资产组合“整体组合收益”的右侧、指标选择框旁增加“更新全部市值”。点击时固定本批账户列表，依次复用现有单账户行情接口，各账户仍使用原配置及先汇率后价格的后端流程；不受当前持仓表的账户/关键词筛选影响，也不根据券商账户同步开关跳过手工账户。不新增后端批量接口或改金融计算，新闻不随此操作更新。
- 按账户显示进度，按钮与即时引用双重防止重复点击；账户返回失败或 HTTP 异常后继续其他账户。结束后汇总完成、部分完成与失败数量，折叠展示各账户原始结果；无新数据属于完成。成功部分保留，结束后重新读取组合与应用数据；刷新失败独立提示，更新结果仍可查看并再次操作。
- 该按钮是当前页面的手动操作，不是后台任务；离开页面后停止派发后续账户，正在处理的账户请求仍可能完成。未加入自动定时更新或自动重试。
- 账户记账“事项”列使用现有表格的多选筛选，复用已有事项名称；先筛选全部账目再分页，支持重置，作废记录仍按原类型可查。表格按账户重建，防止切换账户后残留条件与页码，不修改记录或纠错/作废行为。

## 验证与边界

- `npm run build` 通过，包含 TypeScript 与 Vite 构建；保留已有大包提示，未扩大到打包优化。
- 隔离 Chrome 中使用实际组合/记账组件及虚构响应，15 项交互检查通过：依次更新、防重复、HTTP 失败继续、部分成功汇总与刷新、新日期展示、无新数据、刷新失败恢复按钮、第二页账目筛选、多选与作废记录、重置、切换账户及离开页面停止后续请求。截图已查看，结果留在忽略目录 `.runtime/c034/`。
- 首次浏览器启动受运行环境限制，改用获准的隔离无界面浏览器；测试脚本随后修正初始页面等待、原生折叠详情点击及表格重置会关闭菜单的预期。未以修改业务行为迁就测试。离线响应只证明前端请求和交互，不代表本轮重新验证真实 SDK、正式 HTTP 服务或真实账户操作。
- 仅改三个前端文件，不运行无关后端测试或全套回归；没有启动/重启前后端、访问真实账目或更新其报价。现有后端的来源覆盖、失败保留与历史汇率规则保持，不能把按钮理解为所有市场或品种均支持自动取价。
