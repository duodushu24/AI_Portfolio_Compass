# C-027：最近有效报价、收益补录提示与持仓日期列

## 问题与实际修改

旧导入规则要求历史节点有同刻/同批报价，只允许当前视图沿用较早真实报价。部分更新会使历史节点误判缺价，资金进出又将净值收益率置为未知；原代码同时隐藏盈亏金额，并在估值缺失时漏累计明确的资金金额。普通价格/汇率沿用也被列入黄色估算警告。

- Prices 对当前和历史统一选用实际时间不晚于该点的最近有效单位价格，乘当时数量；保留原报价日期、类型和来源，不写回事实。原导入账户仍不使用交易成交价作为市场报价，跨账户成交不覆盖其已保存估值；明确标记的估算可以使用且保留身份。拆分按比例调整并标估算，红股后不继续使用失效单位价。
- 金额和净值收益率分别判断。只缺资金边界估值而净外部资金明确时，仍累计资金并计算盈亏金额，收益率保持未知；资金折算本身未知时净入金也保持未知。累计结转、成本、现金和已有基准不变，不迁移真实账目。
- 当前估值、统计期、累计计算分别返回结构化缺失项：账户、日期、标的/币种、所需字段及补录入口。前端按当前口径合并提示，预填现有市值表单的账户、历史时间及标的；缺期初价格/成本/汇率/历史人民币成本则回到起点纠错，仍先试算后保存。已清仓或转出的历史标的可以补单位价格，零数量不提供总市值换算。
- 资产组合当前持仓在市值价后新增“市值更新日期”，按北京时间日日期展示原价格实际时间。合并行若跨账户日期不同，显示最早日期并可展开查看；缺价不伪造日期。表头改为“成本价”，摊薄公式和原公式提示不变。不新增报价记录表或节点悬停明细，普通沿用不再黄色报警；明确估算及其他计算说明折叠保留。
