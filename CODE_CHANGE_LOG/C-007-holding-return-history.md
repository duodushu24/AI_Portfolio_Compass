# C-007：持仓历史和手工收益曲线第一阶段

> 后续设计状态（2026-10-13）：本文为既有实施的历史记录。S-001 已归档、原后续阶段停止；当前设计为 [S-002](../issues/solutions/P-005/S-002-account-ledger-performance.md)。本文的“阶段 II/III”仅表示当时未实施范围，不用于安排当前开发。原提交、验证结果与限制保留，不代表 S-002 已实现或完整账户功能已验收。

## 目标与范围

当时落实 [P-005](../issues/P-005-portfolio-return-history.md) 的 S-001 阶段 I（[原方案已归档，仅用于历史追溯](../issues/solutions/P-005/archive/S-001-average-cost-return-curve.md)）。保留现有 React/FastAPI/SQLite；该批次只交付持仓观察历史和持仓收益曲线，未启动成交成本自动结转、已实现/累计收益、现金净值、外部采集或 Agent 工作流。

## 实际修改

增加 `HoldingObservationBatch` 和 `ReturnObservation`，持仓补充批次、成本有效性、可选人民币剩余成本及作废标识。SQLite 启动迁移仅新增字段/表，旧行不推断为完整批次或平均成本，也不恢复曾被删除/覆盖的数据。新金额计算用 Decimal；观察的十进制输入与结果以字符串存储，源持仓沿用已有字段。

`holding_history.py` 按账户、实际时间及批次重建状态：完整成功批次清理声明范围，局部只更新涉及标的，完整空批次有效；旧行只影响自身标的。完整导入需选择账户/市场范围和统一实际时间，默认局部。改变导入范围/时间后的确认不被同文件去重忽略；相同事实可纳入新声明批次，不同事实在同一键上拒绝覆盖。导入失败回滚批次和持仓。Futu 只为成功读取的市场范围声明完整性，原成本字段含义不清时仍为未知；未实测真实 OpenD。

手工保存默认追加“记录新状态”，纠错明确选中旧记录；删除变为作废错误事实，不让更早记录复活，也不生成卖出。作废后的数量/成本在收益计算中为未知，不能当作已清仓；重新核对新状态或完整范围后消除未知。数量 0 或完整范围遗漏可以表达不再持有，历史仍保留。

收益观察保存范围、实际时间、当时采用的价格/单位净值及其实际时间、来源/类型、获取时间、汇率和确认成本。按剩余成本加权汇总组合与同标的跨账户收益；人民币外币成本需取得/期初确认依据，不用观察时汇率倒推。成本、报价、汇率或数量单位未知时不输出完整收益率；可保存不完整记录并查看覆盖情况。未完整核对的账户范围、旧价和估算明确提示。修改/补录持仓刷新派生结果，固定报价保持原值；原有确认与人民币成本只复用到相同数量/均价/币种事实，不使用哈希链。

新增 `/api/returns` 下的 draft、observations、series、history 和账户 empty 接口；观察支持新增、编辑、删除。各账户组合和币种分别成曲线，启用账户变化后可选择旧账户范围，不静默拼接。新增持仓页收益面板：自由时点录入、范围/币种/日期筛选、观察详情、灰色缺失点、橙色已知成交标记、按需标的图，以及历史/as-of、旧记录维护和空仓确认。图按真实观察时间连接，空缺断开，不生成日线。金额显示沿用资产隐藏开关。成交详情来自已有 Deal，展示实际成交和最近前后观察，包括完整空仓边界；明确不是成交时点收益或已实现盈亏。

## 实施细化与限制

市场范围按统一编码比较，旧 SH/SZ 等别名仍归入 CN；收尾检查补齐这一点后，仅重跑受影响的范围、重确认导入和失败回滚 3 项，结果通过。

旧观察编辑时，已失效的成本确认/人民币成本不会重新预填；币种更正后，不把原币报价换一种币种解释。收尾新增并通过这一案例，再仅验证受影响的 4 项成本/币种合同及前端类型检查。

- 纠错保持原标的和实际时点，主要纠正数量、成本、价格等；去掉原先 12 小时近似定位和合并冲突行的逻辑。其他标的/时点走新增状态。批次时间与范围的整体编辑未提供，错误日期需要作废、规范补录并核对当前状态。这是阶段 I 的明确交互限制。
- 价格观察与持仓事实分离：不会自动改变持仓表原记录的价格、数量或账户资产/现金。调仓需在现有成交入口维护事实，数量变化不会自动生成买卖；成交与新持仓观察需分别核对。
- 股票和基金按所输入数量单位计算；尚未支持的资产单位（如期权合约乘数）标为缺失。当前费用仅展示来源记录，不计算平均成本结转、卖出利润、事件精确收益归因或累计曲线。
- 手工路径独立于 K 线；没有拆改既有自动行情拉取链，也未新增真实行情适配器、历史汇率采集或基金净值校验。旧持仓的未知完整性/成本需要核对，未自动迁移历史私有资料。
