# C-001：日记第一阶段：原文保存与管理

## 目标与范围

实施 P-001 / S-01 第一阶段：独立日记原文的数据表、直接年月日 Markdown 保存、复盘入口、列表和编辑。不包含第二阶段 AI 提炼或 P-002 分析工作流。

## 实际修改与进度

新增独立 `investment_diaries` 表与 `/api/diaries` 接口，提供新增、按普通 ID 编辑、详情、日期范围与文字搜索、分页及文件重试。正文保留用户输入，不要求关联证券账户或成交，标题/主题/关键词可选。

在“复盘”中增加投资日记页，提供录入抽屉、列表、原文详情和编辑；默认日期为本地今天，未保存内容离开页面、切换工作区或关闭时有提示，保存期间阻止工作区切换。原有成交复盘保留在另一标签页。

数据库为记录入口，Markdown 为人工阅读副本；正式根目录用 `PERSONAL_KNOWLEDGE_DIR` 配置，未设置则落在忽略的本地 data 目录。本机忽略的 `.env` 已指向现有投资知识库；演示目录固定为独立 `data/demo_personal_knowledge`，忽略正式根目录设置。

按 `YYYY/M月/MM.DD.md` 直接写正式文件，无临时 Markdown。同日独立条目汇总到同一文件，原文纠错重新生成当日内容；日期调整更新原日与新日，旧日空时保留简短说明。数据库先保存；文件失败返回明确的部分成功状态，普通 ID 与待重写日期支持重试，不重复新增。不使用内容哈希或历史版本，也未修改旧日记、历史表格或 H2。

本批次仅实现原文管理；已确认提炼的数据表和界面、模型调用及 Agent 检索均留待后续阶段。README 的当前能力已同步。代码与公开测试仅含虚构内容。
