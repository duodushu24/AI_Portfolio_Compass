# C-016：数据读取减重、计算复用与页面分区加载

关联 [P-008](../issues/P-008-data-loading-performance.md)。按用户已确认的四项性能范围实施，不改收益口径和账目事实。

## 实际变更

- 同一请求的数据库 Session 缓存不同范围/截止时间/精简模式的重放；事实 flush 和事务结束失效。持仓、账户资产及报价投影复用同一次计算。
- 历史估值计算不反复拷贝清仓交易列表；当前保留清仓信息，买卖前仅保存实际用到的数量/成本两个标量。旧完整 API 保持兼容，新增 current/chart/records 视图和确切历史点详情接口，首页及记账读取改用所需视图。
- 复盘批量查询报价及已有记录，普通 GET 在临时对象中更新展示结果，不再提交整批复盘；同步、明确行情刷新及意图保存仍走写入。临时复盘使用稳定成交关联，可首次保存意图。
- 前端按页面读取，各区域单独接收结果，删除失败后的整组串行重试；过期页面请求不得更新当前页面状态。首页继续读取所需复盘摘要，独立于资产展示。
- 合并在途 GET，部分资料读缓存 30 秒、健康检查 5 秒；缓存最多 64 条，键包含工作区后端及完整查询。写前/写后与切换工作区均清空，写后通知当前页面刷新；明确刷新绕过缓存。GET 不再默认发送 JSON Content-Type，减少跨域预检。
- 移除账户概览数组变化触发的额外记账加载；曲线初次读取只有标量数据，点击时读取当时持仓、现金、资金流及成交变化。

## 验证与结果

- 13 项后端相关用例通过，涵盖精简/完整的当前结果一致、逐历史点详情一致、相同时间事项定位、一次重放、事实修改及提交/回滚失效、只读复盘及首次保存意图，另含既有摊薄成本/现金分红和复盘保存回归。曲线详情调整后重跑直接相关 3 项通过，不重复运行无关测试。
- 3 项前端缓存用例通过，覆盖合并请求、查询/工作区隔离、过期重取、失败重取、写后失效以及旧响应不可回填。前端构建通过。
- 正式私有数据只读核对：优化前后完整结果一致，精简视图 current 与旧基准一致；普通读取在 SQLite mode=ro 下成功。重载和浏览器读检查前后，账户、账本、成交、复盘、快照、报价表摘要均未变化。
- 本机正式 HTTP 单次测量：首页约 0.18 秒/60 KB、持仓约 0.14 秒、组合曲线约 0.17 秒/125 KB、复盘约 0.44 秒；账户概览/期初核对约 0.69/0.67 秒。此前首页约 1.70 秒/3 MB，复盘 45 秒超时；前后为不同时刻测量，不作为严格同环境基准。
- 独立无界面浏览器：故意暂停复盘请求时首页仍显示资产；资产组合首次进入约 336 ms、缓存返回约 63 ms；StrictMode 合并请求、账户概览/记账仅各加载一次、清仓页及历史点 API 可用，无 JS 异常。结果只代表本机本次检查，不等于用户体验验收。
- 早期验证遇到默认 pytest 临时目录权限错误，改用项目忽略目录后通过；一个本机 HTTP 检查遇到自动审批超时，获准重试后完成。浏览器初版计数包含 OPTIONS，修正为实际 GET 后通过。

私有基准、接口结果与浏览器日志仅留在已忽略的本地运行目录。未运行完整测试集，未验证其他设备、长期大量数据或外部行情服务；按 P-008 留待实际使用验收。
