# C-002：日记分析、讨论恢复与总结确认

## 实际修改与进度

2026-10-07 用户批准方案并授权开发，本批次已完成实现与直接相关验证。

新增独立讨论会话/消息、已确认总结、标签和总结标签关联表，启动时创建新表并初始化八个简短主题标签。会话先保存用户问题，再调用模型并保存完整回复；按普通会话/消息 ID 恢复或主动重试，已完成轮次不重复调用。进程重启将未完成生成标记为中断，不伪造答案或自动再次调用收费模型。

日记模型调用复用设置中的提供方配置，使用独立教师提示词及 JSON 响应解析，保留分析原话，不经过组合报告的文本替换与字段归一化。明确授权后只发送选中原文、当前会话背景和已完成问答、标签定义；外部总结建议标签只发送正文与标签库。上下文超限明确报错，旧聊天仍可查阅，本批次不接联网检索或历史画像。

“复盘 → 投资日记”提供 AI 分析、录入总结和标签库。支持初次分析直接确认、连续追问后整理总结、候选手工修订和进度自动保存、关闭/刷新后恢复、完整问答回看。外部总结可纯手工保存，也可转入讨论并保留原平台来源说明。原文、讨论和已确认总结分别管理；日记和总结详情均可回到关联记录。

每个日期一份当前已确认总结，可有多次讨论。新问题使旧候选待重新整理；确认前不写正式总结或新标签，确认更新前保留原内容。已确认总结与新标签事务一起入库，随后直接写年月日 Markdown；文件失败显示部分成功并支持普通 ID 重试。聊天只保存在私有数据库，不生成临时文件或聊天版本链。

标签支持名称、定义和别名维护，名称/别名冲突检查，改名保留 ID，主动合并迁移关联与候选标签，并更新已确认总结阅读副本。简单日期/标签/文字查询服务记录管理；未改 Agent 投资分析工作流。正式和演示数据库/文件隔离，真实运行配置、历史资料及原文均未写入或迁移。
