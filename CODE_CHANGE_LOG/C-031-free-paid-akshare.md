# C-031：免费付费数据源管理与 AKShare

## 实际修改

- “AI与高级设置”增加免费源/付费源卡片。统一后端目录声明真实工厂、能力、市场、分组和表单字段，前端动态生成；去掉未实现来源的可用选项。AKShare 免费默认启用，富途在付费源按需启用；Marketaux 保留“免费额度、需 Key”的可选兼容。
- 新增本地通用配置表 `data_provider_configs`，保存启用、行情/新闻优先选择、连接参数和必要凭据。页面配置优先，兼容已有环境变量及账户明确选择；密钥不返回明文，留空保留、显式 null 清除。修改配置清除旧检测状态，已配置不再冒充联通成功。
- 新增统一目录/保存/公开示例检测接口。检测实际取数，检查价格、日期、币种/单位或新闻字段；不写报价、交易或估值账目。账户页的手工/Excel 账户也可更新行情和新闻，并可跳转统一设置。
- AKShare 固定为 1.19.3（Python >=3.11），实现沪深股票/ETF 不复权收盘价与日线、基金正式单位净值和境内个股新闻。股票/ETF 用 AKShare 新浪接口，基金/新闻用东方财富接口，不另维护直连实现。当前未完成日线不作收盘价，单位净值不使用累计净值替代，价格日期与获取时间分开；日精度以收盘边界表示并保留精度元数据，不声称原始秒级时间。
- SDK 在有超时上限的子进程中运行，避免没有超时参数的 SDK 调用卡住 Web 请求或修改全局网络设置。实际网络、依赖缺失、无数据、字段变化、授权不足和未覆盖资产分别提示；不自动换到付费源。旧债券类型的基金经基金代码目录确认后取 NAV，不修改原账目类型/单位。
- 更新路径按真实来源选择，复用同标的两分钟内缓存，每个标的独立保存点；部分失败保留成功项与旧值。同一时点重复价格不重复估值，冲突或币种/单位不符不覆盖。新增报价元数据 JSON 列保存价格口径、实际日期、获取时间、币种单位及实际上游；启动时只增列，不迁移真实记录。
- 行情通过已有独立估值路径处理，延迟不等于估算，不改成交、分红、现金、持仓数量或成本。Agent 工具读取统一缓存并附来源/日期，取消富途代码前缀限制；新闻空值明确不能解释为没有事件。旧复盘优先读取缓存日线，富途同步/复盘/诊断技术资料只在明确启用后连接，并使用统一连接配置；本批不迁移 Agent 框架或增加指标算法。
- README 中英文更新免费默认、可选富途、实际覆盖和依赖说明，增加 Windows 手动启动与开发者扩展位置。没有修改本机 `.env`。

## 验证与限制

- 定向测试共 30 个不同用例通过：`test_data_sources.py` 20 项、`test_providers.py` 4 项、`test_trade_review.py` 5 项、诊断卡关联场景 1 项。覆盖配置优先级、密钥、免费默认/付费关闭、重复与跨账户复用、部分失败、报价冲突、币种单位、收盘过滤、基金口径、新闻去重、路由处理函数、检测不记账及 Agent 只读；使用虚构内存 SQLite 和 SDK 替身。未运行全套测试，路由处理函数验证不宣称 HTTP 传输验证。
- 实际公共请求：新 AKShare 适配器股票、ETF、基金 NAV、个股新闻四条路径均取得非空数据。初次东方财富股票/ETF SDK 请求出现连接错误，改用 AKShare 新浪日线接口；后续直连成功不能据此断言错误根因或长期稳定性。
- 新建 Windows / Python 3.13.9 独立虚拟环境按完整 requirements 安装成功。另复制应用源码到无 `.env` 的忽略目录，用空内存数据库、无个人 Key 并阻止 `futu` SDK 导入，实际调用目录、健康处理、更新与检测：3 条公开行情、500 条日线、10 条新闻成功保存；ETF/基金新闻明确不支持；数量、成本、现金不变，检测未增加账目。样例为公开股票、ETF 和基金，全部虚构持仓，非真实账户。首次样例把基金单位误填为 share，被正常校验拒绝，修正为 fund_unit 后通过；没有修改业务校验以迁就样例。
- TypeScript/Vite 构建通过，保留既有包体积提示。无界面 Chrome 离线实际组件 17 项交互通过：免费/付费页、默认引导、保存失败/重试/重新读取、富途可选配置、检测反馈、密钥不回填/清除、手工账户按钮、跳转及脚本错误检查；截图已查看并调整卡片按钮对齐。虚构扩展源由后端目录生成，前端无需增加服务商判断。
- 忽略目录 `.runtime/c031/` 保存安装环境、源代码隔离副本、公共取数结果、虚构页面资料及截图。正式前后端未启动/重启，真实数据库与账户未改写，未调用外部模型。
- 真实富途权限/新闻、Marketaux 自带 Key、正式 HTTP 页面联调及用户实际操作未验收；离线页面与公共 SDK/内存处理结果分别报告。港美股免费行情、基金/ETF 新闻、银行黄金自动报价、自动汇率及文件导入优化不属于本批交付。免费上游可变，一次成功不保证持续可用或数据再分发许可。
