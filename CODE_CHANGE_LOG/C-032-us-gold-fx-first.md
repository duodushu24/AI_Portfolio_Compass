# C-032：美股、黄金与汇率更新

## 实际修改

- 用户确认扩展 C-031：复用免费 AKShare，补齐美股股票/ETF、国际金价折算和汇率；顺序必须先汇率后价格，汇率失败沿用最近一次有效记录。统一目录新增 FX 能力、按能力限制市场及检测项，前端生成美股、金价、汇率检测入口；AKShare 默认卡片排在免费源首位，不另建配置页或报价表。
- `akshare_global.py` 与现有境内适配器组合：美股使用 `stock_us_daily(adjust="")`；按纽约时区处理冬夏令时，常规收盘后留 15 分钟才采用当日记录，保留美国交易日。提前收市日仍保守等至常规收盘，不把盘中日线称为收盘价。
- FX 使用 `currency_boc_safe()` 的 SAFE 日度人民币中间价，首批取 USD、HKD，按原报价单位 100 外币归一成 1 外币对应人民币。原始记录只有日期，保留日精度并以日常 09:15 发布边界参与未来时间校验；中间价不标作收盘汇率。同批共享 SDK 结果，失败也共享，避免逐币重复网络重试。
- 国际黄金取新浪 `XAU` 伦敦金现货参考/CFD 日线，不使用 COMEX `GC` 期货。仅采用已结束的 UTC 日期，收盘边界是保守的日期锚点，不声称上游提供秒级成交时间。人民币/克＝美元/金衡盎司 × USD/CNY ÷ 31.1034768；记录原始金价、日期、汇率和换算依据。此为市场参考估值，不等同银行赎回报价；仍保留各银行产品独立代码，手工报价可继续维护。
- `market_fx.py` 先请求、校验并保存所需汇率，完成后 `sync.py` 才进入股价/金价请求。美元现金、待确认款项和负债也计入所需币种；纯现金账户可以仅更新汇率。失败、不合法或上游日期较旧时，沿用当前账目/真实缓存里最近的有效记录，保留原始时间，不按缓存过期天数丢弃，不使用固定数值。没有任何有效记录时明确缺失，仍保留成功取得的美元股价及旧的黄金人民币报价。
- 自动汇率在已有估值事件中保存实际日期及 `available_from`，从接收完成时刻开始参与估值；不因今日 09:15 中间价晚些获取而重算之前成交的人民币成本，取数期间的新成交同样受保护。人工明确补录/纠错原有历史规则保持。来源缓存复用现有 `exchange_rates`，不用它替代带日期的历史账目，不新增数据库表或列。
- 黄金只在明确的 `international_spot_fx`、CNY、gram 条件下接收参考报价，普通证券报价仍不能覆盖黄金。估值更新不改实际成交、克数/股数、原币现金、费用或成本；现金折合人民币的金额会随汇率正常变化。重复汇率及相同价格不重复记账，部分失败保留成功和原有事实。
- 页面显示实际采用的汇率及日期；美股市值日期优先显示市场交易日，黄金标“参考”。来源检测使用公开示例，不写报价或估值；金价检测也先取 FX。币种展示优先复用这份已保存汇率，保留未建立统一记录时的旧 Frankfurter 展示兼容路径；该旧路径的固定值不进入本批正式估值。
- 增加显式 `tzdata` 依赖以支持 Windows 纽约时区，更新 README 的实际覆盖、顺序、回退及黄金参考口径；未改本机 `.env` 或真实数据库。

## 验证与边界

- 51 个不同的定向用例覆盖通过：新增跨市场文件 19 项（含参数化）、C-031 数据源 20 项、来源路由 4 项、展示 FX 6 项、既有历史汇率账目 1 项及独立黄金报价失败保护 1 项。检查覆盖先 FX 后价格、单位、DST、盘中/未来过滤、汇率原日期与长期沿用、旧数据不覆盖新数据、缺失不填固定值、纯现金、黄金分数克/实际手续费/清仓、幂等、检测只读、展示复用及更新前/取数期间的历史成本不变。均为虚构内存或隔离 SQLite、SDK 替身；未运行全套回归。
- 初次新用例存在 Decimal/float 比较、遗漏非空缓存到期字段及误用返回字段的样例问题，修正后定向补跑通过。旧账目选择组第一项历史 FX 检查通过后，在黄金 HTTP 请求处阻塞，已结束该测试进程；该组后续未运行的 HTTP 场景不计通过。改用内存服务验证费用/清仓，并单独完成既有不依赖 HTTP 的黄金保护场景；不重复尝试已知环境阻塞，不宣称 HTTP 传输通过。
- 真实公开 SDK 请求：SAFE、AAPL、VOO、伦敦金 XAU 均返回数据。在先前新装的隔离 Windows Python 3.13.9 环境复制最新应用源码，无 `.env`、无 Key、阻止富途 SDK 导入，以实际适配器运行虚构内存账本：调用顺序 `fx → AAPL → VOO → QQQ → gold`；取得 4 条有效价格、750 条日线和 1 份实际汇率，原币现金、数量及成本不变，展示与账本 FX 一致。记录在忽略目录 `.runtime/c032/live_result.json`，没有把公共行情写入正式账户。
- TypeScript/Vite 构建通过，保留既有大包提示。离线 Chrome 使用实际来源卡片、组合和持仓组件完成 12 项交互：动态检测与参数、日期/参考标记、FX 失败保留展示、FX 配置保存、手工账户更新/检测及无脚本错误；截图已查看。最初页面样例未启用日期列，按正式资产组合用法补上 `showQuoteDate` 后通过，不修改业务布局迁就样例。
- 页面离线响应与上述真实 SDK/内存账本流程是两类证据，正式 HTTP 页面联调及真实账户使用仍待验收。无外部模型调用，不启动/重启用户正式前后端，不修改真实账目，不自动历史回填。港股免费行情、基金/ETF 新闻、银行专属自动报价仍未扩展；国际金价为明确标注的 XAU 参考，不保证与银行金额一致或上游持续可用。
