# C-023：标准账户起点导入、历史盈亏结转与统一核对

## 实际修改

- PortfolioOpening JSON 增加账户级历史结转金额/说明，缺失保持未知；没有数据库迁移或真实资料补写。独立纯计算器接上期初持仓盈亏与后续资产净变动，纳入/移出、转账、基准重置和全出金后重开与累计金额分开。
- 现有模板下载新增账户起点三页模板；导入预览识别标准起点，支持负摊薄成本、市值换算、明确现金及汇率来源。确认建账事务校验，重复文件不双计，已纠错账户拒绝旧文件覆盖。
- Excel 与手工共用 OpeningEditor，先试算核对，修改后重新试算；统一隐藏旧“新增数据”路径，未建档资料可核对为起点，已建档持仓文件仍仅作来源核对。标准 Excel 不依赖券商连接。
- 累计盈亏完整时作为主金额，否则展示统计期盈亏；收益口径详情披露已知部分和缺失账户。图与收益率仍只在统计期内。首页空态引导标准模板/手工建账。
- 同范围修复：估值表单丢失基准/交易日期与汇率来源质量，成交纠错丢失明确金额，历史补录漏比人民币成本与累计盈亏，旧详情不认摊薄成本，人民币浮盈汇总遗漏、申购独立费漏扣。修正 3 项已核实的旧测试预期。
- 浏览器发现试算 POST 被当作写入而触发全局刷新，导致纠错表单关闭；对明确的只读试算/解析端点跳过写后失效。真实保存的缓存失效保持。
