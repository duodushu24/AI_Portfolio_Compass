# C-008：完整账户账目与净值收益

落实 [P-005](../issues/P-005-portfolio-return-history.md) 唯一当前方案 [S-002](../issues/solutions/P-005/S-002-account-ledger-performance.md)。不继续旧 S-001 的后续分期；不启动 Agent、外部模型或实际行情服务。用户私有账目未自动建档，旧资料保留，未回退代码或私人数据库。

## 实际设计与修改

新增 `PortfolioOpening`（每账户确认一次的期初/纳入/移出日期、原币持仓成本、各币种现金、报价及汇率）和 `PortfolioEvent`（独立资金、报价、必要调整的实际时间、类型、普通 ID 与十进制字符串）。复用 `Deal`，增加 `ledger_data` 和 `is_void`，规范数量/价格/费用与元信息存在 decimal 字符串中；原字段和 raw_payload 保留兼容已有成交复盘。SQLite 仅追加表/列，无私有资料自动转换。

`services/portfolio` 集中平均成本、现金、收益估值及保存。先校验并按实际时间重放，再同事务提交；补录、纠错和作废会重算后续，导致超卖、现金不足或关联款项失效则回滚。买卖只推导一次现金，不另录同一收支。部分卖出不摊薄均价，清仓利润保留，再买入开启新阶段。申购款、赎回应收及确认/到账保持资产连续，分红/利息/费用/换汇不作为外部资本；转账两端用一条事实，单账户和全账户分类分别计算。拆分作为同资产单位的整体调整，只录一次；转托管保留成本。

报价是全账户共享的标的＋币种＋单位时点事实，手工价格或市值任选一种，市值按实际时点数量换算；旧报价/汇率保持日期与来源，报价补录或更正可重算边界。新增同一实际时点采用确定顺序：期初初始化 → 报价 → 范围纳入 → 成交/资金（同类普通 ID）→ 范围移出。如此资金发生时先估值再调整净值份额；不以当前汇率缓存倒推历史，不把已有期初浮盈再加一次。

**实施细化：** 派生快照采用事实重放后按需计算，不增加第二套持仓或收益缓存表。每个点由已持久化期初、成交、独立事件中的固定报价/汇率还原，返回完整持仓、现金、待确认资产、净值份额和质量。修正指定旧事实会改变受影响派生点；今天的新报价不会替换更早时点。现有 `PositionSnapshot`/`AccountSnapshot` 读取者获得不写回数据库的投影对象；原快照继续作为来源。以本地规模优先简单重放，未引入后台队列或事件平台。

`/api/portfolio` 提供期初、买卖、资金/市值、查询及普通 ID 纠错/作废。账户/持仓/详情和既有诊断改用统一投影；账户全范围按建档纳入日期，与 enabled 同步开关分开。已建档后旧手工持仓编辑和独立收益保存接口拒绝双维护；后续持仓导入保留来源并提示核对差异，规范起点后成交导入进入同一账目，成交 ID 防重。

前端集中在 `features/portfolio`。账户与数据提供期初资料、买卖、资金、市值表单及纠错/作废；持仓展示净值曲线和金额切换；橙色买卖点可查前后数量、成本与本次利润。统一标的详情包含成本盈亏、成交历史与按需曲线，清仓仍可进入。旧记录提供只读来源查询，K 线不作为收益前置。

## 验证进度与限制

相关隔离合同共 40 个已有通过结果：`test_portfolio_ledger.py` 19 项（含 SQLite 追加升级保留原成交与账户纠错成交号冲突）、旧 `test_return_history.py` 16 项、`test_trade_review.py` 5 项。38 项组合检查通过后新增升级检查，并补齐期初缺失与人民币取得汇率边界，账目文件 18 项通过。收尾只重验涉及基金份额、范围/投影时点、共享报价、缺失值和导入的 8 项；旧行情日期与成交号冲突的 3 项；清仓详情/K 线缓存响应的 1 项，均通过，未重跑无关全套测试。Decimal 28 位上下文用于新计算，非法/非有限数字、超卖、现金不足与数量单位错配拒绝，未知及零成本均不用于除零收益。

`npm run build` 最终通过，保留既有大包提示；未做无关拆包重构。隐藏 Edge、隔离 FastAPI/Vite 与虚构 SQLite 完成期初→买入→部分卖出→入金→关联转账→手工价格→全部卖出→已清仓详情→调仓点明细→刷新持久化；无 JS 异常。流程还发现并修复返回同一标的详情时旧 React 状态未刷新。最终账户切换、分账户现金、期初时间可改和汇率实际时间表单的只读浏览器复核通过。合成截图仅在忽略的 `.runtime/s002-ui.png`，服务与数据库均未指向用户正式工作区。

期初估值缺失时，后续市值不能替代期初收益起点；补录期初时点后重放，完整资产/收益才恢复。外币买卖没有成交时汇率依据，则保留原币成本，人民币成本/卖出利润不补造；曲线可采用明确标注的沿用汇率估值。场外基金资产类型/份额单位有一致性校验，避免导入时默默形成第二份持仓。账户同步停用不阻止手工记账，也不改变业绩纳入范围。

报价读取与行情适配器接入路径仅用合成资料核对；本次未调用外部模型或真实 OpenD。适配器返回旧收盘价时保持原报价日期，观察时间为本次取得时点，不生成建档前资金事件；旧价不会压过更晚有效报价。相同代码/报价时间的缓存复用；同时间不同价格需明确纠错，避免重复拉取撞唯一约束。普通 ID 更正账户遇到该账户已有相同成交号时拒绝，双方来源保留。

本地实施提交在批次收尾后回填 `commits`；不包含运行数据库、日记、浏览器截图或工作区既有无关文件，不推送。技术验证只用虚构金额；真实账户期初、历史人民币成本来源及实际使用验收仍需用户核对。稳定行情、K 线恢复、复杂融资/期权数量单位、建档前完整利润恢复和自动历史迁移不在本批次范围。
