# C-025：累计与统计期收益切换及日曲线展示

## 实际修改

- 右上角新增累计收益率和累计盈亏，与原统计期收益率/盈亏共四项，默认累计收益率。摘要金额、摘要收益率及曲线同范围切换，资产与现金不因展示变化；替代 C-024 固定累计摘要的安排。
- profit.py 统一派生当前和历史点的累计净投入及累计收益率（金额除以同一时点净投入）。多账户按汇总金额计算，不平均账户比例。净投入非正或累计资料缺失时收益率为空，不影响可用金额；图表轻量响应保留新增字段，未修改存储事实或增加重放。
- 抽出 PortfolioChart.tsx 负责 SVG、日记录和交易组交互，chartLayout.ts 负责日期/日分组、指标、刻度和布局。纵轴始终有 0 / 0% 及加深零线，其他刻度取整齐间距。
- 曲线每天显示最后一次有效净资产估值，保留当天全部记录供展开；最后估值的收益率不适用时不回退较早比例。收盘模式的真实交易继续单独标记，无估值日不虚构收益点。
- 日期优先估值日，否则按北京时间取日。横轴与曲线提示统一日期格式，无时分秒或“收盘”；首节点与跨年首节点显示年份，其余月日。逐节点日期用 11px、上下错行，按日期间隔排列并在密集时横向滚动。金额曲线轴、提示及摘要遵守资产遮罩。
- 累计曲线从已有记录开始、可非零，不补画建档前走势；净值统计期口径与累计净投入口径分别说明。累计视图不因净值区间编号变化自行清零，缺失收益率处断开；既有后端基准选择和历史可见范围不变。
