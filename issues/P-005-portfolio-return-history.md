## 问题与目标

资产分散于多个账户，覆盖 A 股、港股、美股及场内/场外基金。目标是在本地系统记录全账户持仓、买卖、资金和价格，自动计算摊薄成本、现金、持仓盈亏、阶段清仓收益、账户总资产及累计组合收益。

新账户默认从首笔交易前的现金开始，也可先设置零现金再录首笔入金；首次买入自动建立持仓、成本与报价。已有持仓仍可作为明确的统计起点，日常只记录买卖、资金变动和更新市值。已有账户需要追溯时使用“补录更早历史”，试算核对原起点后统一重建，避免旧期初与历史买入重复计入。主图统计已录入区间的全账户净值收益率和盈亏，起点由真实记录决定，不以软件建立日期为固定边界。

手工市价/净值或标的市值更新即可形成真实观察点，支持任意时点、同日多次和历史补录；记录实际报价时间。先完成手工闭环，稳定自动行情及 K 线不作前置。周复盘只是使用习惯，不固定记录间隔。

金融应用是功能体验参照，不保证不同平台的收益公式一致；本项目明确统一计算口径、起点、账户范围和准确/估算状态。

## 关键选择与当前边界

以期初、规范成交、独立资金及报价为事实；原持仓观察和导入批次只作来源核对，已建档后不与规范账本重复决定持仓。所有页面复用同一后端计算，前端负责输入和展示；后端 API 保留单账户计算用于账目核对，主页面只展示整体账户级曲线。

摊薄成本与净值份额各有用途：前者解释持仓/阶段盈亏，后者计算包含现金和资金进出的组合收益。当前资产减基准资产减净外部入金得到金额，不用累计收益率乘当前资产，不重复加分红或清仓利润。改变收益基准不改成本。

当前及历史估值按实际时间、来源与质量区分；当前可以显示带原日期的已知真实报价，历史缺失不由今天价格补齐。后来保存但实际时间更早的汇率允许重算，未来实际汇率禁止倒填；人民币取得成本未知仍未知。期间真实交易必须保留标记，但不虚构盘中或每日收益。

“账户与数据 → 数据管理”提供持仓、已清仓、成交、行情和新闻查询；账户记账提供买卖、资金、分红、市值和历史补录。历史补录先试算，再核对差异后保存；非法账目事务回滚。快照按自身日期核对，仅完整快照可用缺席标的推断零持仓。

保持 React/Vite、FastAPI、SQLite 和现有业务服务，不新增泛化事件平台、队列或 Agent 工作流。金融应用是体验参照，收益基准、费用、汇率及未知历史成本差异必须说明，不承诺所有外部 App 的收益数值无条件一致。
