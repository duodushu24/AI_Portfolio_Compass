# P-010：统一账户起点导入与历史盈亏结转

## 当前进度

用户在 P-009 评审后确认产品应服务风险承受度、资产配置和低频管理，并授权按讨论设计实施。C-023 已完成本批代码、隔离服务检查、前端构建及虚构账户浏览器检查；尚未操作正式账目或取得用户验收。

2026-10-19 用户反馈旧记录缺少删除入口、累计盈亏被统计期金额替换，并明确要求历史结转留空默认为 0。[C-024](../CODE_CHANGE_LOG/C-024-source-delete-cumulative-display.md) 已恢复未建档来源持仓/成交删除，统一手工、Excel 和旧记录读取默认零，主指标固定累计盈亏；成本或估值缺失时直接提示账户，不把统计期金额冒充累计。18 项收益/导入检查、删除处理函数隔离核对、前端构建及 12 项离线浏览器检查通过；未启动前后端、未修改真实账目，实际使用待验收。

当前详细设计为 [S-001](solutions/P-010/S-001-onboarding-profit-carry.md)。用户最终明确：历史结转盈亏是账户级已实现部分，不关联标的、不增加现金、不改变持仓成本；期初累计盈亏由历史结转加期初持仓盈亏组成。此前讨论中将结转理解为已包含持仓盈亏的历史账户总收益，已被此口径替代。

## 目标与有限完成条件

- 任意账户均可使用标准 Excel 或手工资料建立同一记账起点，不要求富途连接或完整历史流水。复用既有页面，先试算后保存。
- 历史结转可正、可负，未填按 0 计入，可后续补填；已保存的非零结转不被默认值覆盖。旧字段缺失或 null 同样按 0 读取，无需迁移真实账目。
- 累计盈亏始终作为主指标；成本/估值等缺失时显示待补齐及缺失账户，完整核算账户合计与统计期盈亏分别说明，不自动替换主指标。
- 未建档旧来源持仓和成交可单条删除；已建档派生持仓通过起点纠错或原账目作废维护。
- 累计金额接上历史与期初持仓盈亏，后续按资产减期初资产减净入金计算；基准重置、全出金及再入金不清空结转。收益率与曲线仍仅覆盖有依据的统计区间。
- 已建档账户持仓不能直接覆盖；旧模板用于核对，旧账户无新增结转字段时不自动改账。未建档旧资料可在统一表单中核对后建立起点。
- 技术验证已有依据；当前剩余事项是上述实际使用验收，不增加所有券商适配、自动行情或完整历史收益率作为前置。

## 本批取舍

历史结转先以 CNY 保存，外国持仓的人民币成本无依据时仍未知；不以当前汇率伪造。广发专用历史重建脚本保留，不增加专用 UI。资金、分红、估值继续使用现有记账入口；本批不新增券商格式、批量资金/估值模板或新的行情提供方。现有读取缓存和账本复用，试算不触发写后刷新。
