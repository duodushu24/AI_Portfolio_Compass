# P-011 / S-001：免费与付费来源统一管理，默认 AKShare

所属问题：[P-011](../../P-011-market-news-data-sources.md)。2026-10-26 按用户要求确认产品方向并更新设计；本文是待实施方案，能力与验证结果仍以代码及后续 C 为准。

## 1. 本次要交付什么

用户使用免费默认来源获取股票/ETF 收盘价、基金净值及首批境内新闻，在已有页面手动更新。需要其他来源的用户，到同一个管理页面启用富途或未来扩展来源。数据接入不要求用户换券商，也不更改已有成本和收益算法。

本批包含 AKShare 实际调用、默认配置和依赖、统一来源目录、免费/付费分组、富途可选配置迁移、真实联通检测以及前端验证。保持本地优先、手动更新和低频管理，不加入盘中订阅、自动买卖或每日强提醒。

港美股免费来源的全面覆盖、新付费服务商、自动汇率、银行黄金自动报价、批量历史回填、文件导入优化和 LangGraph 迁移不列为本批必须交付项。已有可用来源的兼容行为不应因本次重构被静默删除。

## 2. 免费与付费怎样管理

在现有“AI与高级设置”中增加一个“数据源”区域，内含“免费源”“付费源”两个分组；账户与数据页提供跳转链接，不再要求在每个投资账户中重复配置公共来源。

| 分组 | 本批处理 | 用户看到的信息 |
|---|---|---|
| 免费源 | AKShare 为全新安装的默认来源，覆盖明确列出的市场和品种 | 默认状态、支持范围、检测结果、最近成功更新；不要求 Key |
| 付费源 | 富途 / moomoo OpenD 收纳于此，用户按需选择 | 启用状态、OpenD 连接配置、检测、权限和费用说明 |
| 已有其他来源 | 仅保留真实实现与既有配置的兼容，不在本批增加服务商 | 按真实费用方案登记；未实现能力不能作为可用选项 |

“免费/付费”是展示分组，费用说明、是否有免费额度、是否需要 Key、是否需要服务账户分别保存。富途按用户要求归入付费源，但卡片注明“需 OpenD 登录及相应行情权限，实际费用按服务商规则”；不宣称每次请求收费或一定需要证券开户。

Marketaux 当前有免费额度且已有部分实现，不能仅因需要 Key 就称为纯付费。本次保留其既有配置与调用兼容，如保留选项则标明“免费额度、需 Key”；不把它改成默认、不新增海外覆盖承诺，也不借本批增加新闻服务商。其复用实现必要时从富途适配器中分离。

迁移的是富途连接、授权说明和来源选择入口，实际投资账户仍在“账户管理”。不迁移/删除真实账户、持仓、交易或历史报价，不改券商来源字段，不自动登录/启动 OpenD，不购买权限。

全新安装的付费源默认关闭。已有明确选择与配置保持可见且不无提示覆盖，空配置采用免费默认；更新仍由用户点击。未配置、未启用或无权限的付费源不阻断 AKShare，免费失败时也不静默切换到付费调用。

## 3. 页面具体怎样使用

### 数据源管理

- 免费页只突出 AKShare 默认卡片，展示真实覆盖范围，提供“检测连接”；不展示大量未实现的候选来源。
- 付费页用相同卡片展示富途与以后登记的来源，可按来源配置、启用、检测并明确选择适用市场/数据类型。行情来源与新闻来源分别选择，默认规则按市场和品种匹配，不能只按账户名称选择。
- 配置字段由后端目录提供。例如富途为 OpenD 地址和端口；普通 API 为其所需 Key 等字段，不收集券商登录密码。密钥值保存在本地私有配置，只返回脱敏状态，不进入公开目录或日志。
- 使用一个按来源 ID 索引的本地通用配置记录保存启用状态、连接参数及必要凭据，不按每个来源创建专用表。优先级为页面明确保存的配置、已有环境变量、来源目录默认值；未提交密钥保留旧值，显式清除才删除。沿用环境变量可让既有安装继续使用，不能借此建立额外的账户或资产管理体系。
- 有免费额度的来源如需注册，可如实展示，但不影响免凭据默认流程。
- 首页、健康检查和首次空系统引导不默认探测未启用的富途，不把 OpenD 离线当作系统故障。新用户可以先建立手工账户，不以登录富途作为进入工作台的必要步骤。

### 账户与数据

- 继续提供手动“更新行情”“更新新闻”；手工账户与 Excel 账户同样可用，不再被“是否支持券商账户 API 导入”限制。
- 显示本次使用的来源及更新摘要；同一标的跨账户只抓取一次，统一复用价格事实。
- 仅对实际支持的资产开放自动更新；不支持的显示“该类型暂不支持自动获取，可手动更新”，不报“连接失败”。
- 失败给出来源、原因和可执行操作，例如“AKShare 未安装”“请求超时，请稍后重试”“来源暂未发布新净值”“缺少授权 Key”“富途对应行情权限不足”。无新数据、解析错误和网络失败分开。
- 保留当前持仓的“市值更新日期”，不增加独立报价明细表或日常强制检查流程。

## 4. 一处登记，前后端共用

统一扩展入口沿用 `backend/app/services/providers.py`，整理为包含真实适配器工厂的来源目录。来源描述至少包括 ID、名称、免费/付费分组、费用说明、已实现能力、支持市场/资产类型、凭据要求、配置字段及适配器入口。

能力按实际实现分别登记，例如价格、正式基金净值、日线、新闻、账户快照。注册名称不代表能力已实现；不因某一方法可用就宣称整个来源全部可用。公开目录不含密钥，不提供未实现来源的成功检测。

前端通过一个目录接口获得分组、表单字段和可选能力，移除 `marketDataProviderOptions`、`newsDataProviderOptions` 和来源凭据说明等重复硬编码。扩展点的职责如下：

| 位置 | 职责 |
|---|---|
| `adapters/akshare_adapter.py`（拟新增） | 调用 AKShare，将价格、净值、历史和新闻返回转换为项目标准结构 |
| `adapters/futu_adapter.py`（已有） | 保留富途账户与行情接入，按需加载依赖、尊重实际权限 |
| `services/providers.py`（已有） | 唯一来源目录、分组、能力、配置字段、真实适配器选择 |
| `services/sync.py`（已有） | 手动更新组织、批量去重、校验及保存，去掉固定创建富途适配器的路径 |
| 后端来源配置/检测接口 | 统一目录读取、配置与实际检测；复用相同结果格式 |
| 前端数据源组件 | 读取目录生成分组卡片和配置表单，不写服务商专用判断链 |
| `profile_agent_tools.py`（已有） | 读取统一缓存/计算结果，移除仅允许富途代码前缀的限制 |

开发者接入新付费 API 的最小步骤是：新增实际适配器、在统一目录登记一次、补充该适配器的必要验证与依赖。普通配置字段和能力不再要求手工修改 React 来源名单。不同 API 的协议仍需要实现，不能承诺仅填写 URL 就能适配任意数据。

## 5. AKShare 首批能力与数据口径

| 数据 | 首批目标 | 必须分清的口径 |
|---|---|---|
| A 股日线 | 已完成交易日的日线及收盘数据 | 普通日线的当前未收盘记录不能当成已确认收盘价 |
| 场内 ETF | 交易所市场价格与日线 | 持仓市值使用交易价格，不使用 ETF 基金净值替代 |
| 场外基金/债券基金 | 正式单位净值、净值日期 | 不用累计净值或盘中估算替代单位净值；债券基金不是交易所债券 |
| 境内新闻 | 实际可取的个股新闻标题、来源、发布时间、链接 | ETF/基金覆盖单独说明，关键词匹配不冒充基金公告 |
| 未覆盖资产 | 港美股等按本批真实实现显示，不做默认承诺 | 明确不支持并保留手动价格，不能偷偷调用富途 |
| 银行黄金/汇率 | 继续沿用已有手动维护 | 不用国际金价替代银行具体产品价格，不伪造汇率 |

保留系统代码，来源内部完成代码映射；已知市场/品种可自动匹配，模糊或单位冲突提示确认，不能根据资产名称猜测后直接写价。当前历史资料中存在类型不规范的记录，接入时需验证债券基金等关键路径。

标准返回明确标的、币种、单位、价格或净值、价格日期/时间精度、获取时间、来源 ID、实际上游和价格口径。仅有日期的数据保留日精度，不将获取时间伪装为价格时间。历史分析用的复权序列与账户估值用的不复权价格分开，延迟数据不自动标为估算。

新闻统一标题、原始来源、发布/获取时间、原文链接、关联标的及数据状态；不默认抓取全文，不把返回空列表说成“市场没有事件”。根据原文链接/来源标识去重，真实发布时间未知时保持未知。

AKShare 是接口库，其许多接口使用东方财富/天天基金等上游；直连相同上游不能算独立备用源。本批优先采用 AKShare 并锁定验证过的依赖版本，不另维护重复的东方财富直连产品实现；前序直连试取仅作网络/上游诊断证据。

## 6. 获取、入账与未来 Agent 的边界

行情及新闻先由普通 Python 适配器获取并校验，统一缓存。用户手动更新市值时，将有效价格通过现有独立估值事实路径保存；不改交易数量、成本、分红或现金。重复取同一事实幂等；相同来源/实际时点的冲突值不能静默覆盖，失败不清空历史值。手动估值与不同来源的同日记录保留来源和先后，不将切换来源当成删除历史。

联通检测只试取公共示例并校验结果，不写入用户账目。配置齐全仅表示“已配置”，实际请求并验证结构后才标可用；能力、依赖、凭据、网络、解析、权限及无数据状态分开。

未来 Agent 使用框架无关的查询函数，返回普通 JSON。读取账户/收益服务与行情/新闻服务，不直接导入 AKShare SDK；查询分析资料不能顺便生成账目估值事件。报告保留资料截止时间与所用记录引用，避免分析途中数据更新导致口径混用。本批不引入 LangGraph，只为后续动态工具调用保留接口边界。

## 7. 实施顺序与验收证据

1. **统一目录与选择路径**：后端实际目录、配置/能力接口、免费/付费分组；保留旧明确配置、空配置默认 AKShare，去掉前端重复名单及富途固定调用。
2. **AKShare 真正接入**：安装依赖、股票/ETF/基金与新闻适配、公共示例实际请求、字段校验、日期/代码/单位映射、超时与有界重试；将所得数据接入统一保存路径。
3. **页面闭环**：免费默认、付费可选配置/检测、手工账户可更新、结果摘要与错误处理。富途只在显式选用时调用；连接失败不影响其他来源。
4. **新安装与前端验证**：隔离数据、无个人 Key、无 OpenD 的安装与操作检查，再记录构建、真实上游和页面各自结果。没有真实联调证据时不能声称完整端到端通过。

必须覆盖的有限验收场景：

- 全新环境依安装说明自动装齐默认依赖，免费行情不要求证券账户、API Key 或富途 SDK/OpenD 可用；启动文档不再把 OpenD 写成所有用户的必需项。
- 股票、ETF、场外基金各取一条公共真实示例，校验市场/单位/实际日期和价格口径；新闻实际请求校验字段和链接，空结果与请求失败分开。
- 在前端看到免费/付费分组，免费默认 AKShare；未配置富途不出现阻断性错误。保存配置、刷新页面后选择保持；未实现的来源不能被误选为可用。
- 实际点击更新后显示正确来源及价格日期；同一标的跨账户不重复抓取，重复点击不重复记账；部分失败时保留成功结果与原有失败项值，并列出具体原因。
- 富途可选配置和故障提示可用；服务未启用时不连接 OpenD，默认来源调用不进入富途代码。账户管理中原投资账户仍在。
- 新增一个虚构来源仅改适配器/注册入口，前端动态出现相应分组、字段与能力；证明扩展路径，不宣称虚构来源具有真实行情。
- 取数不修改买卖数量/成本/现金/分红；只读查询与联通检测不保存账目；既有手动报价及日期保持。
- TypeScript/Vite 构建和必要的离线实际组件交互通过，真实取数另行验证。前端验证使用隔离资料，不默认启动/重启用户正式前后端；受环境限制无法完成的联调明确列为缺口，不能用 mock 或演示数据冒充实测。

验证按风险运行直接相关检查，不为本方案运行全套测试。实现后的 C 保存具体命令、结果、截图位置和边界；当前仅完成设计，没有上述验收结果。
