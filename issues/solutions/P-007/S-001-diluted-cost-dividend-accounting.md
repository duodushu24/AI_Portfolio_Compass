# P-007 / S-001：唯一摊薄成本与现金分红结算

所属问题：[P-007](../../P-007-diluted-cost-dividends.md)。创建/更新：2026-10-17。

当前唯一方案，按用户最后确认的简化范围实施。不保留平均成本算法或成本切换开关；P-005/S-002 的基础账本、账户范围与净值原则继续使用，旧成本和部分卖出已实现盈亏规则由本方案替代。实施证据见 [C-015](../../../CODE_CHANGE_LOG/C-015-diluted-cost-cash-dividends.md)。

## 1. 已确认范围

- 用户不需要精确恢复每日收益曲线，后续以手工周度或其他实际观察为主，不补造每日价格。
- 不实现除息价格归因、应收分红、登记日/除息日到到账日的跨日资产平滑，也不新增自动行情和公司行动抓取。
- 市值使用真实报价，保留来源和时间；旧报价标注旧价，不能将分红再从实际报价中扣一次。
- 唯一使用摊薄成本。持有期间部分卖出盈亏统一落入浮动盈亏，当前阶段未归零不生成清仓收益；数量归零立即结束阶段，之后买入重新计算，包括同日回补。
- 现金分红按实际到账记录，不改成本，归属原持有阶段并计入该阶段最终清仓收益。已到账的历史流水不重复计现金。

## 2. 唯一计算规则

按账户、代码、币种和单位确定持仓；每阶段维护数量 Q、买入实际清算支出 B、卖出实际清算收入 S，以及现金分红净额 D。

```text
摊薄净投入 N = B - S
Q > 0：摊薄成本价 = N/Q；浮动盈亏 = 实际市值 - N
当前阶段未结束：不生成清仓收益，部分卖出不单列已实现盈亏
Q = 0：清仓收益 = S - B + D；归档后成本金额归零
再次买入：新阶段的 B/S/D 从零开始，旧阶段结果继续留在清仓查询
```

买卖清算金额已含费用。买入加入实际支出、卖出减去实际净收入，不再按平均成本结转。负成本和零成本合法；仅当 N>0 且市值已知时输出持仓盈亏率 `(市值-N)/N`。清仓收益率以本阶段累计买入清算支出 B 为分母，B>0 且成本已知才计算，并在页面说明；尚未核对券商该百分比字段，不能由金额匹配宣称百分比也完全一致。

拆分/红股只增加或调整数量，不改 N；转托管按数量比例携带净投入，不制造卖出或清仓收益，转入基准与真实首笔买入区分。跨币种按明确交易时汇率记录历史净投入和现金分红的人民币金额，缺失时不拼凑人民币清仓收益。

旧平均成本快照不是已确认摊薄成本，不直接改名复用。旧类型或未知期初成本保留未知并提示重新确认，允许确认合法的负期初摊薄成本。旧 API 的 `average_cost` 等字段名仅作为兼容别名，值与新增 `diluted_cost` 完全同源，并明确 `cost_method=diluted`，不构成第二种算法。

## 3. 现金分红归属与后续录入

每笔分红保留账户、标的、币种、净到账金额、真实到账时间、来源流水及持有阶段。现金变动只有一次，后续补充归属不产生新现金事实。

- 仅有唯一可归属阶段时可自动匹配。已经清仓并重新买入、有多个历史阶段时，用户必须选择原阶段，不能默认计入最新持仓。
- 持有期间到账：现金增加，D 增加，N、数量及浮动盈亏不变。
- 清仓后到账：现金增加，修正已关闭原阶段的分红、清仓收益和清仓收益率，新阶段成本不变。
- 对已有未带标的的旧分红，现金事实继续有效，但列为未归属、清仓收益待核对；本次券商导入来源明确的分红，通过原始流水补标的/单位信息后重放，不再次入账。来源不明不猜测。
- 更正、作废仍修改原事实并全量重放，不能通过追加另一笔现金模拟更正。

不根据价格下跌生成分红，也不建立分红到账前的应收资产。周度或其他观察可能跨越尚未到账的分红，页面只反映已记录现金与实际报价，不能宣称精确每日总回报；此限制由用户明确接受。

## 4. 账户总收益与展示

账户总资产仍为持仓市值、现金及既有待确认资产减负债，期间盈亏仍为总资产变化扣除外部资金流。分红增加的现金已经在总资产中，不再将 D、清仓收益或卖出收入加一次。分红不是外部入金，不增加组合份额。

本次不改变账户净值/份额算法。资金流边界估值不完整时保留缺失，不因成本变化生成精确收益率；原有明确报价和当前旧价提示继续保留。

持仓表使用摊薄成本价、浮动盈亏和本阶段分红，移除部分卖出已实现盈亏列。清仓查询只列已结束阶段，拆出买卖盈亏、现金分红和总清仓盈亏；详情提供净清算金额及分红到账记录，不再展示平均成本结转与逐笔卖出利润。分红录入提供标的和持有阶段选择。

## 5. 数据切换与有限验收

不重导成交、改期初现金或改写价格。先备份正式数据库，在副本中补齐必要分红关联、按真实账目重放，核对现金、数量、相同报价下总资产不变，且用户核对的成本/清仓样本一致后切换正式读取。只更正来源明确的分红归属元数据；个人金额和源文件留在忽略的本地运行目录，不进入公开文档或测试。

最小验证：部分卖出、费用、负/零成本、同日清仓回补、持有分红、清仓后迟到分红、重新买入后归属选择、分红纠错不重复计现金、实际汇率及缺失情况、转托管不清仓、旧期初成本不误判，以及总资产/现金守恒。本轮不测试每日曲线复原、除息归因或应收结算。
