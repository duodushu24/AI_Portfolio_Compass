# P-007 / S-001：摊薄成本、现金分红与除息估值

所属问题：[P-007](../../P-007-diluted-cost-dividends.md)。创建/更新：2026-10-17。

这是当前唯一的成本与分红变更设计。用户已确认核心口径，本轮补充后续分红和除息设计；尚未实现。P-005/S-002 继续负责基础账本、账户范围及净值/份额原则，其中旧平均成本和部分卖出已实现盈亏的计算在本方案实施后被替代，不保留为另一套可切换算法。C-007 至 C-014 作为旧实现事实保留。

## 1. 唯一成本与持有阶段

以账户、标的、币种和数量单位定位持仓，以独立阶段标识关联买卖与权益。每阶段维护数量 Q、累计买入实际清算支出 B、累计卖出实际清算收入 S、摊薄净投入 N=B-S、已结算现金分红 D，以及明确的应收分红。

```text
Q > 0：
  摊薄成本金额 N = B - S
  摊薄成本价 = N / Q
  浮动盈亏 = 当前实际市值 - N
  持仓盈亏率 = 浮动盈亏 / N，仅 N > 0 且市值已知时输出
  当前阶段不产生清仓收益，部分卖出盈亏不另加一次

Q = 0：
  清仓收益 = S - B + D
  有关联分红待结算时标注当前清仓收益尚非最终值
  建议清仓收益率 = 清仓收益 / B，仅 B > 0 且成本已知时输出
```

B/S 已包含实际交易费用，不再加扣费用。直接修改平均成本结转公式及消费端，不以保留旧平均成本为实际核算基础再补一个显示字段。负/零 N 合法，不能强制为零或禁止合法交易；相关收益率显示不可用。未知期初成本保持未知，不能把旧平均成本价改名当成真实摊薄成本。

任一卖出使数量归零即结束阶段；随后重新买入重置 B/S/D，包括同日重新买入。旧阶段交易、盈亏和分红不滚入新成本；迟到分红仍可调整旧阶段清仓收益。拆分/红股只调整数量，成本金额不变。转托管携带对应成本和权益归属，不视为卖出盈利或普通清仓。

分红不降低 N、不进入上述浮动盈亏。持有期间可单独展示本阶段分红/待到账权益。对从首次投入及建仓开始、无期初历史浮盈亏、无汇率及其他事项的人民币账户，核对关系为：当前持仓浮动盈亏 + 当前未清仓阶段的已收/已确认应收分红 + 已关闭阶段清仓收益 + 归属关闭阶段的待结算应收分红 + 利息 - 独立费用 = 账户总盈亏。关闭阶段已结算分红已经包含在清仓收益内，不再加一次。

## 2. 后续现金分红的三类日期

不能只用到账时的持仓数量认定权益。至少区分权益登记日、除息日、公告发放日及真实到账时间；公告发放日不等于本地流水的真实到账时间。

| 时点 | 记录与资产处理 | 成本/阶段处理 |
|---|---|---|
| 公告及权益登记 | 保存来源、每单位分红、登记时点实际享权数量，核对所适用市场规则；仅公告不增加现金或收入 | 锁定有权收息的原持有阶段，不按后来当前数量计算 |
| 除息生效 | 权益与金额有明确依据时确认应收分红；现金仍不变。实际证券报价按未复权价格估值 | 不改 N；应收属于原阶段，不按外部入金增份额 |
| 实际到账 | 按实际净额增加现金，同时结清对应应收；税费/差额独立核对。应收转现金是资产形态转换，不再增加第二次收益 | D 只确认一次，更新原阶段；即使已清仓并重新买入也不归入新阶段 |

有应收未到账时，已清仓阶段显示已结算清仓收益及“待分红结算”状态，待结清后形成最终净额；账户总资产则计入有依据的应收，不能因标的清仓而丢弃。

总资产 = 未复权证券市值 + 现金 + 已确认应收/其他待确认资产 - 负债。分红不是外部入金，不增组合份额。已确认应收结算后再把到账额当额外利润，会重复确认收益，必须拒绝。

### 最小记录与去重

- 分派事项：稳定事项标识、标的/币种、公告来源与日期、登记/除息/发放日期、每单位税前分红及已知税费口径。
- 账户权益：账户、原持有阶段、享权数量、已确认应收额及其税前/税后状态、实际到账净额、税款/费用或未定状态、关联流水标识和结算状态。
- 同一事项支持不同账户、分批到账与更正；事项与现金流水分别去重，禁止公告、导入流水和手工补录各加一次现金。
- 首次迁移时，既有分红到账流水已是真实现金事实，只补标的/阶段/事项关联。缺少登记/除息日时不倒造应收日期；后续补齐依据再显式重算，不静默改变历史。
- 权益或税费不确定时记录待核对，不将未知净额视为零，也不把税前金额标成确定的税后收益。无法可靠确认应收净额/已知负债时，历史收益质量标为缺失或未核对。
- 本次只设计现金分红；分红再投、配股、复杂跨境扣税按实际新增事实独立处理，不自动假设为现金到账。

## 3. 除息变化和市场变化如何区分

需要区分“证券价格变动”与“含分红的投资回报”，但一笔报价仍只有一个实际价格。不得因为已记录分红，再从真实除息后报价扣一次红利，也不得用复权价格乘实际份额计算真实持仓市值。

保存独立的公司行动/基金分派事项，在标的详情和历史观察上标注除息日期、每单位分红及来源。实际价格、除息参考价、复权/未复权类型分别保存。没有可靠公告或行情元数据时，不能把价格下跌自动归因为分红。

只在有可靠前收盘、官方除息参考价和当期实际报价时，展示如下参考分解：

```text
总价格变化 = 当期实际价格 - 除息前实际收盘价
除息基准调整 = 官方除息参考价 - 除息前实际收盘价
相对除息基准的价格变化 = 当期实际价格 - 官方除息参考价
```

这是按参考基准作的算术分解，不是对交易价格变化的精确因果证明。仅有公告公式时可以解释理论参考价，但不能当作实际报价或用它补齐历史市值。现金分红、送转、税费等应使用对应公告和市场规则，不把纯现金分红的简化公式推广到全部公司行动。

### 虚构例子（不是用户账目）

持有 1,000 份，原价 10 元，每份现金分红 0.20 元，官方除息参考价 9.80 元，实际报价 9.85 元，忽略税费且没有交易：

- 证券市值从 10,000 元变为 9,850 元；现金或已确认应收分红为 200 元。
- 合计资产为 10,050 元，总收益是 +50 元，不是证券单看价格的 -150 元，也不是到账时再额外赚 200 元。
- 若 N=10,000 元，持仓浮动盈亏为 -150 元，单列分红权益 +200 元；不为避免持仓显示负数而改变成本或市场价格。
- 实际价相对除息参考价上涨 0.05 元；该参考分解不得被命名为精确剔除所有非市场因素后的收益。
- 现金尚未到账时用有依据的应收维持资产连续性；到账后现金增加、应收减少，总资产不因结算再增加。

## 4. 对收益率与最新报价展示的约束

账户总盈亏继续使用总资产减期初资产及净外部资金流，不能将清仓收益、分红或卖出收入再加进资产。份额净值法不变；分红及应收结算不增减份额，组合内转账不当作整体外部入金。成本口径变化本身不应改变相同事实及估值下的账户总盈亏；新增有依据的应收会修复过去除息到到账之间的资产确认时点，该变化必须单独说明。

缺少历史报价、权益或资金流边界估值，仍不生成完整精确历史收益率。当前可显示带日期的最新已知真实报价；若只有除息前的旧价格，就不能将该旧价与除息后的应收/现金相加宣称为完整估值，否则会高估资产。除息后缺价需明确显示未核对或当前市值不可用，等待真实除息后报价，不能自动减去分红当成新行情。

新旧持仓数据必须区分原成本类型，旧平均成本快照不与新摊薄成本直接做同口径比较。外币分红保留原币、实际税费及相应时点的明确汇率；汇率缺失不拼凑完整人民币收益。

## 5. 实施范围和有限验收

1. 替换成本与阶段引擎，联动当前持仓、跨账户合并、详情、清仓查询及兼容 API；移除旧部分卖出已实现盈亏展示，只有关闭阶段进入清仓统计。
2. 为分红补充标的/阶段/事项关联、应收确认与到账结算，复用现有资金入口及导入去重能力；不重新增加历史到账现金。
3. 价格观察保留真实日期和价格类型，增加明确除息事项标记、旧单位/除息前报价失效保护及必要的参考解释，不扩大为自动行情或公司行动抓取项目。
4. 使用私有副本隔离重放，先核对实际交易、现金与阶段，再核对新派生指标。用户已核对的私有证券账户样本只在本地测试/验收结果保留，不写入公有文档、测试或 Git。

最小验收包括：部分卖出吸收盈亏；负/零成本；同日清仓回补；现金分红不改成本；登记后卖出仍收息；除息与到账跨日；已清仓/重买后的迟到分红；分批到账/更正/税费未知；重复导入；真实除息后报价不二次扣红利；除息前旧报价不能与分红双计；外币缺汇率；无分红标的不受公司行动错误影响。

建议清仓收益率分母使用本阶段累计买入清算支出，但用户尚未核对券商百分比字段；不得由金额匹配推断百分比也完全一致。当前规则文档不构成功能实施或真实数据迁移授权。
