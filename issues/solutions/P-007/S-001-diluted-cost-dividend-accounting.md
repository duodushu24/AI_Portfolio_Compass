# P-007 / S-001：唯一摊薄成本与现金分红结算

所属问题：[P-007](../../P-007-diluted-cost-dividends.md)。更新：2026-10-18。

当前唯一方案。用户确认以“分红视同到账、现金和成本同步变化”替代 C-015 的“分红不改成本”。新实施见 [C-017](../../../CODE_CHANGE_LOG/C-017-manual-dividend-cost.md)；C-015 保留历史事实，不再作为分红成本的现行依据。

## 范围与计算

以手工记录为主，不增加后续账单导入去重、应收分红、除息归因、跨日到账处理或每日估值重建。收益统计起点及缺失历史估值规则不变。

按账户、代码、币种、单位及持有阶段维护数量 Q、买入清算支出 B、卖出清算净收入 S、净分红 D：

```text
持仓净成本 N = B - S - D
Q > 0：摊薄成本价 = N/Q；持仓盈亏 = 实际市值 - N
未清仓：不单列清仓收益，部分卖出和分红已计入持仓盈亏
Q = 0：总清仓收益 = -N = S - B + D
清仓展示的买卖盈亏 = 总清仓收益 - D
再次买入：新阶段的 B/S/D 重新计算，旧阶段结果保留
```

费用只计一次，净分红必须大于零；原币和人民币成本分别按明确记账汇率处理，缺失人民币成本/当时汇率时保持未知。负/零成本合法，非正成本不输出误导收益率。清仓收益率仍以累计买入支出为分母。

未知期初成本不因分红变成已知。拆分/红股不改净成本；转托管按比例携带扣减分红后的净成本，不制造清仓收益或额外现金。兼容 API 的 average_cost、floating 字段分别对应摊薄成本和含分红的持仓盈亏。

## 手工入口与展示

- “账户记账”新增独立“记录分红”，复用 dividend 事件，不加入买入/卖出方向。旧资金类型中的分红入口兼容保留。
- 填写账户、标的、记账时间、净分红金额；币种随标的，手续费通常为零。旧非零税费记录纠错时保留费用并明确扣费前金额。记账时间视同到账，默认关联该时点当前阶段，历史阶段可手动选择。
- 新录保存前按所填时间预览现金/成本变化或历史清仓收益变化；已有记录的纠错、作废直接重放，不追加一笔现金。
- 当前阶段分红：现金增加、净成本扣减，数量与市值价不变。历史清仓阶段分红：现金增加，修正原阶段收益及收益率，新阶段成本不变；无法明确归属时拒绝，不猜测。
- 持仓表改称“持仓盈亏”，提示已含分红及部分卖出；分红列仅作拆分披露，不能再相加。清仓保留买卖盈亏、分红、总盈亏拆分。

## 总收益与既有记录

总资产继续由持仓市值、系统现金及既有待确认资产减负债构成。分红不是外部入金，不增加组合份额，不将持仓盈亏或分红再次加到总资产。市场价格另外按真实报价记录，分红不自行下调市场价格。

用户明确接受忽略到账时间差，因此系统现金可能短暂领先券商可用余额，不宣称为实时可用资金。已有分红复用原事件重放，不重复增加现金。正式不自动补录未录的新分红；样本先在副本验证，再由用户通过入口手工记录。源事实、期初现金、报价及收益统计起点均不改。

## 有限验收

验证分红降低成本、含分红盈亏、报价与成本独立、清仓只结算一次、历史阶段补录、新阶段重置、纠错/作废、负成本、外币实际汇率及转托管。既有事实下现金/总资产和清仓合计保持一致；虚构账户浏览器验证入口、预览、保存及刷新。
